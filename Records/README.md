# Records — Sample Golden Records

This directory contains **sample golden records** — the final assembled JSON objects that the pipeline produces for each successfully processed problem. These are for reference and documentation purposes only; the live dataset is tracked by DVC.

## What is a Golden Record?

A golden record is the verified, enriched output for a single competitive programming problem. It contains:

- **Problem metadata** — Codeforces ID, title, tags, difficulty rating, contest ID
- **Problem statement** — full HTML and parsed text
- **Oracle solutions** — N reference C++ solutions scraped from top submissions
- **Pseudocode** — language-agnostic algorithm representation (generated by Gemini)
- **Reconstructed C++** — implementation generated from pseudocode (by Groq/DeepSeek)
- **Verification status** — pass/fail against all pretests in the Docker sandbox
- **Code quality metrics** — Cyclomatic Complexity, function count (via `lizard`)
- **Provenance metadata** — timestamps, model versions, attempt counts
